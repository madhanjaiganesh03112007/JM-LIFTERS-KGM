Place your preferred hero background image at this path to use it as the site's default hero.

Filename: hero.jpg
Path: assets/hero.jpg

The admin panel (lock icon) can override this image per-browser using the Upload -> Save Image flow. Clearing the saved image will revert to this default.

Recommended image size: 1800x900px (or wider), optimized for web (JPEG ~200-400KB).
